# Icon source

Icons are downloaded from the selfh.st icon collection (repository `selfhst/icons`,
served via jsdelivr). No icon was drawn or modified by hand.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `svg/watchtower.svg` | Default (full-colour logo) |
| `icon-light.svg` | `svg/watchtower-dark.svg` | Dark-colored glyph for light backgrounds |
| `icon-dark.svg` | `svg/watchtower-light.svg` | Light-colored glyph for dark backgrounds |

Download URLs:

- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/watchtower.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/watchtower-light.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/watchtower-dark.svg
